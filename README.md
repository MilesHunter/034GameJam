# 034GameJam

Unity 2022.3.62f2c1 (2D).

## Run
Open the project in Unity Hub and press Play.

## Controls
- Left click: select ball/stick; click the shape buttons to spawn stick / add ball / delete
- Right mouse drag / WASD: move camera
- Mouse wheel: zoom
- Space: toggle physics pause (for placing)
- Esc: toggle game pause
- R: restart scene
